Sao lưu & Khôi phục kho

Dữ liệu được lưu trong bộ nhớ trình duyệt hiện tại. Bạn nên xuất file sao lưu định kỳ để chuyển sang điện thoại hoặc trình duyệt khác khi cần.

Xóa mục này?

Mục sẽ bị xóa khỏi kho lưu trữ trình duyệt. File gốc trên máy vẫn nguyên vẹn.

Hướng dẫn sử dụng

1. Chạy file HTML lẻ & dự án ZIP

Nếu web của bạn có nhiều file (ảnh, nhạc, CSS, JS), hãy dùng ZArchiver nén thư mục đó thành file .zip rồi thêm vào đây. Hệ thống sẽ tự động giải nén và nối lại toàn bộ đường dẫn tài nguyên.

2. Không bao giờ mất trang khi Reload

Mọi dữ liệu được lưu vĩnh viễn trong IndexedDB. Khi đang mở một trang web, nếu bạn bấm tải lại trình duyệt hoặc thoát app ra vào lại, hệ thống sẽ tự động mở tiếp đúng trang đó.

3. Nút điều khiển nổi (FAB)

Khi đang chạy toàn màn hình, bạn có thể kéo thả nút tròn nổi sang vị trí bất kỳ để không che nút game, hoặc bấm vào để Tải lại, Toàn màn hình, Sửa code nhanh.
